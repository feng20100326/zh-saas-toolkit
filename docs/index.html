多数小团队不需要买四套软件。选型的第一标准不是功能多，而是建站 + 邮件 + 自动化 + 订单 + 会员能不能在一个后台里。

一、选型标准（按重要性）

  1. 一体化：一个后台跑完获客 → 成交 → 交付 → 复购
  2. 起步 ≤ $20/月，爆单时能加量而不是重买
  3. 数据能带走：CSV 导出、自有域名、别被锁死
  4. 中文可用：界面、邮件模板、客服
  5. 推荐归属：链接是"终身归属"还是"30 天 cookie 归零"

四、五个容易踩的坑

  • "终身归属"≠"30 天 cookie"：cookie 到期归零，前期推荐再多也白做。
  • 提现门槛：$10 / $100 / $200 差别很大，推之前先问清。
  • 收款通道先小额验证：中国大陆个人能否收款要在推之前试一次，否则会出现"推了几个月提不出来"。
  • 备案类型别乱填：同一渠道被拒或被删累计 5 次，该渠道所有推广位永久不再跟踪结算。
  • 不要自己买自己的东西：多数联盟条款禁止自购刷量。
国内电商选品另说：要推实物好物就走国内 CPS —— 多多进宝（个人可做、无需店铺资质、不必过媒体备案）、淘宝联盟（需备公开媒介备案）、京东联盟（需完成证件核验）；结算多在每月 20 日前后。佣金由商家自设，本文不做比例承诺。
